♥LOOKING BACK

My Final Reflection

What Web Development Taught Me

These activities showed me how a page can respond to what a person does. I started by changing text with the DOM, moved on to events like hover and double click, then learned to wait for several tasks at once with Promises.

Some of my code did not work the first time, so I learned to read my own scripts line by line and find the typo or the missing piece.

This portfolio puts my activities in one place, and I plan to keep adding to it as I learn more. 💗
